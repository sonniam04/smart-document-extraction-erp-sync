# Spec Delta

## Purpose

ให้ผู้บริหารฝ่ายการเงินเห็นภาพรวมยอดซื้อ ภาษีซื้อ ภาษีหัก ณ ที่จ่าย และประสิทธิภาพของกระบวนการรับเอกสาร ตามช่วงเวลาที่เลือก และส่งออกไปใช้ต่อได้

## ADDED Requirements

### Requirement: Report period
รายงาน SHALL คำนวณตามช่วงเวลาที่ผู้ใช้เลือก (ค่าเริ่มต้นคือเดือนปัจจุบัน ยาวไม่เกิน 24 เดือน) ยอดเงินทั้งหมด MUST นับเฉพาะเอกสารที่ยืนยันแล้วขึ้นไปและไม่ถูกปฏิเสธ โดยจัดเข้าช่วงตามวันที่ในใบกำกับ ส่วนตัวชี้วัดของกระบวนการจัดเข้าช่วงตามวันที่อัปโหลด เวลาทั้งหมดเป็นเวลาไทย

#### Scenario: เอกสารที่ถูกปฏิเสธ
- **WHEN** ในเดือนที่เลือกมีเอกสาร 10 ฉบับที่อนุมัติแล้ว และ 2 ฉบับที่ถูกปฏิเสธ
- **THEN** ยอดซื้อรวมมาจากเอกสาร 10 ฉบับเท่านั้น

#### Scenario: ช่วงเวลายาวเกิน
- **WHEN** ผู้ใช้เลือกช่วงเวลา 30 เดือน
- **THEN** ระบบปฏิเสธพร้อมแจ้งว่าเลือกได้ไม่เกิน 24 เดือน

### Requirement: Spend and tax summary
รายงาน SHALL แสดงยอดรายเดือนของ จำนวนเอกสาร, ยอดก่อนภาษี, ภาษีซื้อ, ภาษีหัก ณ ที่จ่าย และยอดรวม พร้อมยอดรวมทั้งช่วง และผู้ขาย 10 รายที่มียอดรวมสูงสุดในช่วงนั้น ยอดเงิน MUST ตรงกับผลรวมของเอกสารที่นับ (ทศนิยม 2 ตำแหน่ง)

#### Scenario: สรุปภาษีซื้อรายเดือน
- **WHEN** Finance Exec เลือกช่วงตุลาคมถึงธันวาคม
- **THEN** เห็นแถวรายเดือน 3 แถวพร้อมภาษีซื้อของแต่ละเดือน และยอดรวมสามเดือนที่เท่ากับผลรวมของสามแถว

### Requirement: Process metrics
รายงาน SHALL แสดงจำนวนเอกสารตามสถานะ, เวลาเฉลี่ยจากอัปโหลดถึงอ่านเสร็จ, จากอ่านเสร็จถึงยืนยัน และจากยืนยันถึงส่ง ERP สำเร็จ, สัดส่วนเอกสารที่ต้องให้หัวหน้าอนุมัติ และสัดส่วนเอกสารที่ยืนยันโดยไม่มีการแก้ค่าที่ AI อ่าน

#### Scenario: สัดส่วนที่ไม่ต้องแก้
- **WHEN** ในช่วงที่เลือกมีเอกสารที่ยืนยันแล้ว 20 ฉบับ และ 15 ฉบับไม่มีการแก้ field ใดเลย
- **THEN** รายงานแสดงสัดส่วนที่ไม่ต้องแก้ 75%

### Requirement: Report export
ผู้ใช้ SHALL ส่งออกรายงานของช่วงที่เลือกเป็น CSV (UTF-8 พร้อม BOM) ที่มีสรุปรายเดือนและผู้ขายยอดสูงสุด และการส่งออก MUST มี audit event ระบุผู้ส่งออกและช่วงเวลา

#### Scenario: ส่งออกรายงานไตรมาส
- **WHEN** Finance Exec ส่งออกรายงานไตรมาสที่ 4
- **THEN** ได้ไฟล์ CSV ที่เปิดใน Excel แล้วภาษาไทยถูกต้อง และมี audit event ของการส่งออก

### Requirement: Report access
รายงาน SHALL เข้าถึงได้เฉพาะผู้ที่มีสิทธิ์ดูรายงาน (`FINANCE_EXEC`) role อื่น MUST ไม่เห็นเมนูและได้ 403 จาก API

#### Scenario: Clerk เรียก API รายงาน
- **WHEN** ผู้ใช้ที่มีเพียง role `AP_CLERK` เรียก API รายงานสรุป
- **THEN** ระบบตอบกลับ 403
